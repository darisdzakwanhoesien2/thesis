# Bahasa Baku Mock Up Batako dan Paving Block

Setelah dilakukan percobaan dengan menggunakan beberapa pengujian laboratorium dan Ujicoba mandiri diketahui dapat digunakan sebagai Bata Ringan

Aggregate Raw Materials: based on the test results, pure dry tail material can be used as a choice stockpile because it complies with all the specifications described in the General Specifications (2018) - PUPR

Raw Materials for Mock Up Bricks and Paving Blocks: After conducting experiments using several laboratory tests and independent trials it was found that they could be used as Lightweight Bricks
