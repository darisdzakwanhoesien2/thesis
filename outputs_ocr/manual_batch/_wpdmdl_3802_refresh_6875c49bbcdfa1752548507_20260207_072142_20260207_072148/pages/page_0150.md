|  3. KURUSAN  |   |   |   |   |
|  Penerja Kembalian di halaman pemanggulan (T) dan atas nama Tim PT, tentang melakukan pekerjaan pengawasan (tubing, office, klien) dan pada kehidupan 2 meter, sehingga pekerja perlu utat berita bengal/sosifolding. Pada saat melakukan pekerjaan dan kemudian memindahkan kaki karenja untuk bergeser ke area sekitarnya, tempoh, pijakan kaki kanan tidak tepat pada area kampuse, osafolding, kelenika korban terjatuh dan kelenggar. 1,5 meter ke batang kanan, sentak merasa kaki kanan tidak bisa digerakkan dengan sempurna dan merasakan kerakitan. Dari kejadian tersebut korban bertentak (termakas) memanggil pengawasanya yang sedang mengawasi pekerjaan disididimbing sekelamnya. Membosok korban kerakitan pengawas memastikan area aman dan kondisi disekitar dan segera menghubungi Emergency Call PT GM. Tim Emergency-LASO PT GM berusma Paramedic untuk respon membawa peralatan pile dan beberapa alat bantu untuk pemanganan korban.  |   |   |   |   |
