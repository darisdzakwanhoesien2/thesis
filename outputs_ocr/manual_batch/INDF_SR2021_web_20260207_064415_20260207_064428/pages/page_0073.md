# Supporting Potato Farmers through Industrial Potato Seed Production
Mendukung Para Petani Kentang melalui Produksi Bibit Kentang Industri

CBP Group developed an industrial potato seed production program to support the Indonesian Government in reducing the volume of imported potatoes, both fresh potatoes and potato seeds. The program was initiated in 2013 in West Java with screen houses and seeding areas. In 2019, the project was relocated to Humbang Hasundutan, North Sumatra. In 2021, our program has produced more than 20 million seeds.

Grup CBP mengembangkan program produksi bibit kentang industri untuk mendukung Pemerintah Indonesia dalam mengurangi impor komoditas kentang, baik kentang segar maupun bibit kentang. Program ini dimulai pada tahun 2013 di Jawa Barat dengan pembangunan screen house dan area pembibitan. Pada tahun 2019, proyek dipindahkan ke Humbang Hasundutan, Sumatra Utara. Pada tahun 2021, program kami telah menghasilkan lebih dari 20 juta bibit.
