# 1. Great Place to Work

PT Vidio Dot Com (Vidio) for the second time in a row received Great Place to Work certification for the period February 2023-February 2024. This year Vidio achieved a score of 92% as a great place to work with an average Trust Index of 84, or an increase from the score obtained in 2022, which was 90% for a great place to work with an average Trust Index score of 81.

PT Vidio Dot Com (Vidio) untuk kedua kalinya secara berturut-turut mendapatkan sertifikasi Great Place to Work periode Februari 2023-Februari 2024. Tahun ini Vidio meraih skor 92% sebagai great place to work dengan rata-rata Trust Index 84, atau meningkat dari skor yang diperoleh tahun 2022, yaitu 90% untuk great place to work dengan rata-rata skor Trust Index 81.
