# Real-time Dashboard for Monitoring and Optimizing the Production Process
Real-time Dashboard untuk Pemantauan dan Optimasi Proses Produksi

CBP Group's Dairy Cikarang factory, known for producing high-demand dairy products, has introduced an online real-time monitoring system to track essential production parameters. This system features a dashboard that displays data online efficiency, rejection rate, Clean In Place ("CIP") status, start-stop machine, batch mixing status and electricity consumption. With this monitoring dashboard, the factory can quickly identify production issues and critical equipment parameters, thereby preventing downtime and enhancing production line efficiency. Since the dashboard's implementation, the factory has experienced a 20% increase in production capacity. This achievement highlights the expertise of the engineering team that developed the system in-house, contributing to CBP Group's Dairy Division's recognition within the Industry 4.0 digital transformation program.

Pabrik Dairy Cikarang Grup CBP, yang dikenal sebagai produsen produk dairy dengan permintaan tinggi, telah mengimplementasikan sistem monitoring secara real-time untuk menelusuri parameter penting dalam proses produksi. Sistem ini dilengkapi dengan dashboard pemantauan yang menampilkan data secara online terkait efisiensi operasional, tingkat produk reject, status CIP, status start-stop mesin, status batch mixing, serta konsumsi listrik. Dengan adanya dashboard monitoring ini, unit operasional dapat dengan cepat mengidentifikasi kendala produksi dan parameter kritis pada peralatan, sehingga dapat mencegah downtime serta meningkatkan efisiensi pada setiap lini produksi. Sejak implementasi dashboard ini, unit operasional telah mengalami peningkatan kapasitas produksi sebesar 20%. Pencapaian ini menunjukkan keahlian tim engineering, yang telah mengembangkan sistem ini secara internal, sekaligus memberikan kontribusi kepada Divisi Dairy Grup CBP dalam program transformasi digital Industri 4.0.
