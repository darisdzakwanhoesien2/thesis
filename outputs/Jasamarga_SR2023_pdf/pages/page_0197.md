# Meningkatkan Manfaat bagi Karyawan

Jasa Marga berupaya meningkatkan aprèsiasi, dan imbalan bagi karyawan atas kontribusi dan keberhasilannya dalam pelaksanaan tugas. Program aprèsiasi ini dilaksanakan secara adil dan sistematis yang diterapkan sesuai kemampuan Perseroan, melalui program bertajuk FoR MoRe Benefit WE GO.

# Increasing Benefit for Employee

Jasa Marga strives to improve employee recognition and rewards based on their contributions and successes in carrying out their responsibilities. This appreciation program is implemented fairly and systematically, in accordance with the Company's capabilities, through a program called FoR MoRe Benefit WE GO.
