# INVESTASI PADA PROGRAM CSR
# INVESTMENT IN CSR PROGRAM

Investasi yang telah dikeluarkan Perusahaan untuk melaksanakan program TJSL berasal dari biaya operasi Perusahaan dan juga sinergi Program dari Induk Perusahaan. Pada tahun 2017 realisasi penyaluran investasi untuk program TJSL Perusahaan tercatat sebesar Rp16,57 miliar meningkat 17,43% dibanding realisasi tahun 2016.

The Investations that the Company spent on conducting CSR program are derived from the Company's operational budget and synergy program from the holding company. In 2017 the realization of investigation disbursement for the Company's CSR program is Rp16,57 billion, an increase of 17,43%, compared to the realization in 2016.
